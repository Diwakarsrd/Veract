# Agent Runtime (v0.3.0)

A reliable runtime for autonomous agents with verification, memory, and capability control.

## Key Features
- **Contract-first Verification**: Every step is validated against explicit criteria.
- **Persistent Memory**: SQLite-backed episodic and semantic memory.
- **Capability Broker**: Least-privilege permissions for filesystem and network access.
- **Self-Healing Recovery**: Automatic replanning on failure classification.
